Privacy Policy — Oura Home Assistant

Effective date: 15 August 2026

Purpose

Oura Home Assistant is a personal-use integration that connects an authorized Oura account with the user's self-hosted Home Assistant environment.

Data accessed

The integration may request Oura data covered by the permissions the user explicitly grants during OAuth authorization, including account, activity, sleep, readiness, heart-rate, workout, session, SpO2, stress, heart-health, tag, and ring-configuration data where available.

How data is used

Oura data is accessed only to make the authorized data available within the user's Home Assistant environment for personal home-automation, display, history, and analysis purposes.

Data sharing and sale

The application operator does not sell Oura data. The application is not offered as a service to third parties and does not intentionally disclose Oura data to third parties beyond the services and infrastructure chosen by the user to operate Home Assistant.

Data storage

The application operator does not maintain a separate hosted database for collecting Oura data. Any persistence of data is controlled by the user's Home Assistant installation and any storage, backup, or remote-access services the user has independently configured.

Authorization and deletion

The user controls access through Oura's OAuth authorization. Access can be revoked through Oura. Data already stored in Home Assistant can be removed using the user's own Home Assistant data-management and deletion tools.

Security

OAuth credentials and access tokens should be kept private. The user is responsible for securing the Home Assistant installation and any systems on which its credentials or data are stored.

Changes

This policy may be updated if the application's data handling changes. The effective date above will be updated when material changes are made.

Contact

Questions about this policy can be raised through the public GitHub repository associated with this site.
